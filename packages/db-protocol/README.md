# db-protocol

Shared data types for the database services: the `Task` schema and its decode/encode helpers.

- [Effect Schema](https://effect.website/docs/schema/introduction/) — `Schema.Class` models with validation, defaults and wire encoding (UUID, trimmed strings, ISO dates)
- [Vitest](https://vitest.dev) — unit tests (ids generated with [uuid](https://github.com/uuidjs/uuid))
