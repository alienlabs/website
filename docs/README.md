# Alien Labs

## Stack

### Toolchain

- [node](https://nodejs.org) — JavaScript runtime that executes tooling, scripts, and Cloudflare Workers-compatible code.
- [pnpm](https://pnpm.io) — Fast, disk-efficient package manager driving this pnpm workspace monorepo.
- [vite](https://vite.dev) — Dev server and build tool for the web package.
- [storybook](https://storybook.js.org) — Workshop for building and previewing UI components in isolation.

### Infrastructure

- [cloudflare](https://developers.cloudflare.com/workers) — Deployment target for the app, built and shipped via Wrangler.

### Runtime

- [typescript](https://www.typescriptlang.org) — Statically typed superset of JavaScript used throughout the codebase.
- [effect](https://effect.website) — Functional effect system for typed, composable business logic.

### UI

- [solidjs](https://www.solidjs.com) — Reactive UI library that compiles away the virtual DOM.
- [ark-ui](https://ark-ui.com/docs/components) — Headless, accessible component primitives (e.g. Tooltip) used by the app.
- [tailwindcss](https://tailwindcss.com/docs) — Utility-first CSS framework used for styling.
